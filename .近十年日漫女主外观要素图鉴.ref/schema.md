# Workbook Design — 近十年日漫女主外观要素图鉴

> **v2 更新（23:1x）**：按用户反馈扩表为 8 大类 146 项（新增「体型」「年龄」两大类；服装/配饰/属性大幅加码）。最终数据以 fill.py 内联为准（本 schema.md 的 77 项明细为 v1 版本，结构与样式指令仍有效：商务蓝表头、COUNTIF/SUM 公式、筛选+冻结、备注列 240px 换行）。输出文件名：近十年日漫女主外观要素图鉴_全量版.xlsx

> 由 excel-generation skill 在主代理侧产出，供 sheet-agent 子代理按图施工。

## User Intent
把上轮对话产出的「近十年（2016-2026）日漫爆款女主角外观要素图鉴」（77 项、六大类）做成 Excel 表，用户可直接查阅、筛选和统计。

## Scenario Archetype
- 记录型：77 项要素明细清单，需要规范字段、筛选、冻结表头
- 统计型：按大类统计要素数量，供用户快速看分布

## Sheets
- 分类统计（角色：汇总，放在前面，要素数用公式引用明细）
- 要素图鉴（角色：主表/明细，77 行全量数据）

## Sheet: 分类统计

### Columns
| 列 | 字段名 | 类型 | 来源 | 备注 |
|---|---|---|---|---|
| A | 大类 | 文本 | 推断 | 枚举：发型/发色/瞳与面部/服装/配饰/属性；第 2~7 行数据，第 8 行合计 |
| B | 要素数 | 数字 | 计算列 | B2：`=COUNTIF(要素图鉴!$B:$B,$A2)`；填充 B2:B7；B8：`=SUM(B2:B7)` |
| C | 代表要素示例 | 文本 | 推断 | 每类挑 3~4 个代表要素，顿号分隔 |
| D | 趋势备注 | 文本 | 推断 | 一句话观察（见下）；列宽 240px，自动换行 |

### Sample Data Scale
6 行（六类各一行）+ 第 8 行合计。

### Notes for sheet-agent
- 第 1 行：表头。
- 第 2~7 行：六大类数据（发型/发色/瞳与面部/服装/配饰/属性）。
- 第 8 行：合计行（A8 填"合计"，B8 公式合计）。
- 表头：商务蓝 `#4472C4` 底 + 白字 + 加粗 + 居中 + 下边框 thin。
- 计算列按 Columns 表备注公式执行；验证时读回公式文本，确认 COUNTIF 引用 sheet 名（要素图鉴）正确、合计公式覆盖 B2:B7。
- D 列（趋势备注）列宽 240px 并开启自动换行（wrapText）。
- 汇总区（第 8 行）加粗。
- 数据内容：
  - 发型｜示例：双马尾、黑长直、丸子头、呆毛｜趋势：经典发型全制霸，黑长直+双马尾最常青
  - 发色｜示例：粉毛、银发紫瞳、金发、渐变挑染｜趋势：银发紫瞳为 2026 顶流组合，粉毛经久不衰
  - 瞳与面部｜示例：异色瞳、红瞳、虎牙、猫嘴｜趋势：小特征制造记忆点，虎牙/猫嘴=萌点速成
  - 服装｜示例：水手服、西装校服、兔女郎装、魔女装｜趋势：制服系与奇幻系并进，反差穿搭出圈
  - 配饰｜示例：兽耳、蝴蝶结、过膝袜、长手套｜趋势：非人要素加成，兽耳/角/尾巴持续吸粉
  - 属性｜示例：傲娇、反差萌、元气、御姐｜趋势：反差萌=近十年最强人设钩子

## Sheet: 要素图鉴

### Columns
| 列 | 字段名 | 类型 | 来源 | 备注 |
|---|---|---|---|---|
| A | 序号 | 序号 | 推断 | 1~77，居中 |
| B | 大类 | 文本 | 推断 | 枚举：发型/发色/瞳与面部/服装/配饰/属性，每行重复填，便于筛选 |
| C | 要素 | 文本 | 推断 | 要素名称 |
| D | 代表角色 | 文本 | 推断 | 顿号分隔，可多角色 |
| E | 作品 | 文本 | 推断 | 与角色一一对应，顿号分隔；无作品时填"—" |
| F | 备注 | 文本 | 推断 | 一句话说明；列宽 240px，自动换行 |

### Sample Data Scale
77 行（第 2~78 行），数据见下方「明细数据」，按序填写。

### Notes for sheet-agent
- 第 1 行：表头；第 2~78 行：数据（77 行）。
- 表头：商务蓝 `#4472C4` 底 + 白字 + 加粗 + 居中 + 下边框 thin。
- 大类枚举值须与「分类统计」A 列完全一致（发型/发色/瞳与面部/服装/配饰/属性），保证 COUNTIF 统计正确。
- 可用性：开启筛选（数据 ≥ 10 行），冻结首行（数据 ≥ 20 行）。
- F 列（备注）列宽 240px 并开启自动换行（wrapText）。
- 序号列居中；大类/要素列居中或左对齐均可，文字不被截断。
