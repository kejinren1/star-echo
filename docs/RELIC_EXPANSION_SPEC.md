## 3. B 项：构筑转换型套装（玻璃大炮·用户修正版）⭐ P1

### 3.1 设计核心（用户 2026-08-18 20:46 拍板）

> **不做"濒死触发/控血"**：控血流的核心是"极高数值让怪几乎摸不到你、走钢丝"，但本作数值做不出"完全无伤"，硬做体验会崩。
> **改为"构筑转换"**：整套遗物把玩法从"后期堆数值的肉坦"（没人打得动）**切换**为"伤害很高、很少有人摸到你，但每次被摸都是严厉惩罚"的玻璃大炮。

- **具体数值**（占位，可调）：
  - 最大生命上限 **-90%**（初始 100→10；走血量流堆到 200→20）
  - 减伤幅度**大幅提升**：Boss 一个技能只掉 **1-2 滴血**（绝对数值小=减伤兜底）
  - 伤害 / 出伤频率**大幅提升**
- **数值原则**：不做"特别爆炸"的数值（用户明确）；紧张感来自"血量百分比低→被摸的相对代价高"，而非绝对数字大
- 效果 = 高风险高回报的**永久构筑风格转换**，非临时濒死爆发

### 3.2 套装结构

- 遗物数据新增：`set_id`（套装标识）、`set_tier`（1/2 件触发档位）、`set_effects`（套装效果数组）
- 套装计数：inventory 统计当前持有同 `set_id` 遗物数量 → 激活对应 tier
- 示例套装（占位数据）：
  - 「星骸孤注」：单件=最大生命 -90% 且减伤 +40%（Boss 技能≈1-2 血）；2 件=伤害 +100% 且攻击速度 +50%，被摸后 2 秒内减伤再 +30%（惩罚缓冲）
  - 「死线舞者」：单件=最大生命 -70% 且移速 +30%；2 件=移动时每秒叠加伤害层数、停下清零（移动=输出，被摸=停摆，走位收益最大化）
- **装备反馈**：切换构筑时必须有视觉/音效/状态图标变化（否则玩家感知不到"我变成玻璃大炮了"）

### 3.3 验收
① 同套装 2 件激活 tier2；② 生效后最大生命按 -90% 削减、减伤与伤害按设定提升（探针白盒数值断言）；③ 被 Boss 技能击中伤害符合减伤兜底（1-2 血量级）；④ 装备/卸下时状态面板与图标正确切换；⑤ 数据驱动（Excel 或 JSON 扩展字段）

### 4.1 设计

### 4.2 验收
① 未解锁遗物不出现在任何掉落池且不泄露名称；② 达成条件后解锁并可在图鉴查看；③ 失败 N 局后能解锁新遗物（白盒注入 fail_count 验证）；④ 图鉴记录持久化

## 5. D 项：流派遗物树 + 动态权重引导 ⭐ P0（核心新机制）

> 用户原话提炼：**初始池固定 → 按玩家前两轮选择偏好权重引导 → 解锁对应流派物品数后，高稀有流派核心道具才开放出现概率 → 基础物品简单、越倾向越开放复杂质变机制**

### 5.1 流派分层（示例以"移速流"为例，**用户 20:46 拍板：流派不限于移速**——可为攻速流/肉坦流（活活耗死 Boss）/元素流/召唤流等，由方案师按设计空间自由规划，其余流派同构）

> **设计红利（用户明确点出）**：流派树 + affinity 分层天然**规避"武器池太大稀释权重"**的死亡细胞式问题——掉落按流派分层收敛而非全局摊平，新流派加入**不稀释**旧流派体验，池子可以放心做非常大。

| 层 | 稀有度 | 示例 | 开放条件 |
|---|---|---|---|
| T1 基础 | common | 移速 +10；移速 +15 但防御 -3（代价型） | 初始即开放 |
| T2 进阶 | uncommon | 攻击力与移速挂钩（移速的 10% 转为攻击）；累计移动 3000px 触发一次范围冲击 | 该流派已解锁 ≥3 件 T1 |
| T3 核心 | rare+ | 移速满阈值（如 ≥450）时子弹分裂 +1；移动时每秒叠加层数、停下清零、叠满质变 | 该流派已解锁 ≥6 件 T1/T2 |

- **"低速没性价比、移速上来质变"** 是 T3 核心道具的设计标尺：机制写死，性价比随流派数值自然膨胀

### 5.2 动态权重（affinity）机制
- **记录**：每局结束，按本局实际装配的遗物流派打标 → `meta_progress.relic_affinity`（各 tag 计数，如 `{"speed":5,"element":2}`）
- **权重**：掉落/商店出现权重 = 基础权重 ×（1 + 亲和系数 × 该流派 affinity 计数）；亲和系数建议 0.15/次，上限钳制（防单调）
- **意图**：前两轮连续选同一流派 → 第三轮起该流派遗物出现率显著上升 → 玩家感受到"我的选择在塑造掉落池"
- **可改性（用户 20:46 拍板）**：affinity 默认**保持选择不可改变性**（纯累积）；但开放**事件节点**允许玩家修改/洗点（如"重置某流派亲和"或"转移亲和到另一流派"），洗点事件进 10 事件池
- **双向保护**：非主流流派仍有基础权重（不归零），防玩家被锁死在单一流派

### 5.3 数据设计（交 #2 拆解细化）
- 遗物条目新增：`tag`（speed/element/summon/defense/offense/economy…）、`tier`（1/2/3）、`unlock_condition`（见 C 项，T3 用 affinity_tag 类）
- 权重计算放数据层或独立模块（DataLoader.get_relic_pool 扩展），**禁散落各调用点**

### 5.4 验收
① 前两轮全选移速遗物 → 第三轮移速类出现率显著上升（白盒注入 affinity 断言权重排序）；② 未解锁 T3 时 T3 权重≈0；③ 解锁 T3 条件后权重恢复；④ 非主流流派不掉出池（基础权重>0）

## 6. E 项：Boss 宝箱收获环节 + 通关成就感 ⭐ P0（用户明确要求）

### 6.1 设计（参照杀戮尖塔"收获房间"）
- **章 Boss 战后**：不再直接跳下一层/通关界面 → 进入收获房间：
  1. 宝箱开启演出（占位：宝箱图/色块 + 开启音效 + 光效）
  2. 掉落：遗物三选一（复用精英三选一 UI 逻辑）+ 材料/局外货币
  3. 玩家可停留查看属性变化 → 手动进入下一层/结算
- **通关结算页**：展示本局高光数据（击杀数、波次、最终 Build 流派标签、收集的遗物列表）+ 解锁提示（新遗物/新图鉴条目），制造"这局没白打"的成就感
- **新音效特效**：宝箱开启 / 获得遗物 / 购买物品 / 通关（SFX_MAP 零新键契约下按 AF 批次扩展或走 audio_map）
- 购买物品反馈：商店购买成功 = 音效 + 短暂高亮 + 金币 -N 跳字（现状若已有则只补音效）

### 6.2 验收
① 章 Boss 战后必见宝箱环节且可三选一；② 结算页含本局统计+解锁提示；③ 新音效接入（探针验证 audio_map 键）；④ 不打断现有流程（可跳过）

## 7. F 项：Boss 行为节奏调整（走走停停 + 大范围技能主导）⭐ P0（直接改手感）

### 7.1 现状与问题
- BS 技能系统已实装，但玩家体感仍是"Boss 无脑追着跑绕圈"——**行为调度偏追踪、技能施放没有"站定-后摇"节奏**，大范围技能存在感低

### 7.2 目标
Boss 战从"追击主导"改为**"技能主导 + 走走停停"**：
1. **施法站定态**：释放 circle/fan/beam 等大范围技能时 Boss 减速/站定（预警期间不追人），后摇期可被输出——给玩家"躲技能→反打"的节奏
2. **时间分配**：追踪与技能的占比倒置（目标 ≈ 追踪 30-40% / 技能+走位 60-70%），由参数表控制（chase_ratio / skill_window）
3. **大范围技能权重提升**：circle/fan/beam 出现频率 > 贴身追击类（charge/突进）
4. **走走停停的节奏感**：移动段短而明确（逼近到技能射程即停），技能段完整四拍子（预警→决策→结算→后摇），后摇结束再决定下一步

### 7.3 实施位置（交 #2 拆解确认）
- enemy_boss.gd 行为循环（技能循环已存在，调调度权重与站定逻辑）+ enemy_movement.gd（追踪减速/站定）
- 参数数据化（enemies.json phases 或 boss_pattern 表），禁硬编码

### 7.4 验收
① 探针可验证：技能施放期间 Boss 移速下降或站定；② 时间分配比例符合目标（日志/探针统计）；③ 大范围技能出现次数 > 贴身追击；④ 公平底线公式（BOSS_SKILL_SPEC §2.2）零破坏
