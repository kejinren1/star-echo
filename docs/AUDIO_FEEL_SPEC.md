## 〇、现状盘点（2026-08-18 实测）

### 音频侧
- **2 首 BGM**（`assets/audio/bgm/`，各 352KB wav，08-04 占位音源）：`bgm_menu` / `bgm_battle`
- **10 个 SFX**（`assets/audio/sfx/`，3572B~39KB wav，占位合成音）：hit / crit / death / levelup / coin / shop / skill / heal / event / boss
- 管理器 `scripts/autoload/audio_manager.gd`（D24）：BGM 状态机（MENU→menu；BATTLE/SHOP/ROUTE_SELECT→battle；GAME_OVER→stop）+ SFX 池 ×4 轮询 + 懒加载 + 缺资源 push_warning 零崩溃（D31 双护栏）
- 音源生成工具 `tools/gen_audio.py`（占位合成 wav 管线，与 SFX_MAP 路径对齐）
- **BGM 仅 2 轨**：无章节主题、无 Boss 战专属轨、无商店轨——长局（15 关）单曲循环疲劳

### 打击感/手感侧（现状锚点）
- 已有：玩家受击红闪（player.gd:185 `_play_hit_flash`）、受伤相机震动（main.gd:99）、敌人击退（enemy.gd:288 `apply_knockback`，升级冲击波）、暴击通道（weapon_controller.gd:357）、经验飘字、精英/Boss 横幅
- **缺**：hitstop 顿帧、相机震屏分级（命中/暴击/死亡）、命中粒子/残影、击杀慢动作、音画同步（命中音延迟）、敌人受击僵直/抖动、空挥音、技能释放音分层、BGM 随 Boss 血线切换、商店/章节 BGM 差异化
- 手感：移动为即时速度（无加速/摩擦曲线）；攻击无前摇/后摇概念（自动射击）；技能冷却仅 HUD 文本，无音画反馈

## 一、音乐重制方案（多方案，选一或组合）

### 方案 M1【推荐·低风险】免费 CC0 素材库替换
- **内容**：从 OpenGameArt / Kevin MacLeod(incompetech) / FreePD 等 CC0 站点按「Anime 像素 + 星骸废土」风格选曲替换 2 BGM，SFX 换高质量 CC0 打击/射击音
- **改**：仅替换 `assets/audio/**` 文件（文件名不变，SFX_MAP/BGM_MAP 零改动）；audio_manager 无需改
- **验**：headless 加载无 push_warning + 真人听感标记（#5）；回归 baseline
- **工作量**：小（采集+替换）；**风险**：低（纯资产替换）；**依赖**：需网络采集（GitHub 生态可达，见项目网络经验）

### 方案 M2 程序化合成分层 BGM（chiptune 升级）
- **内容**：升级 `tools/gen_audio.py`，按「基调+节奏层+紧张层」分层合成：普通战斗静音→波次推进加节奏→Boss 战加紧张层→血线变化切层；章节 1-4 不同基调
- **改**：gen_audio.py 扩展 + BGM 轨扩展（每章 1 轨 + Boss 轨 + 商店轨 ≈ 8-10 轨）+ audio_manager 增加按 `current_layer/章节/Boss 血线` 切轨/切层接口
- **验**：生成后 headless 加载 + #5 真人听感 + 状态机探针（切轨断言）
- **工作量**：中-大；**风险**：中（状态机复杂度）；**优点**：零版权、可迭代、与 PS-D 章节化天然对齐

### 方案 M3【需拍板】AI 生成音乐
- **内容**：用 AI 音乐工具生成 BGM/SFX 后转 wav 入库
- **注意**：08-07「不再投入 AI 生成」红线仅约束美术，音乐未拍板——**本方案需 Owner 明确同意才进拆解**；且需外部工具/账号（外部动作）
- **风险**：版权归属 + 需外部服务

### 方案 M4 外包/购买授权（外部动作，需 Owner 全程确认）
- **内容**：找音乐外包/买授权曲包；**风险**：付款 = 外部世界动作，红线内必须 Owner 亲自执行，总指挥只出需求清单

### §2 决策点（交 Owner/#2）
1. M1 vs M2 vs M3（免费素材 / 程序合成 / AI 生成）——建议 **M1 先行（低风险立即改善）+ M2 并行（章节化长期）**
2. 若选 M1：采集曲目清单需 Owner 确认（网络下载属外部动作边缘，建议由总指挥在 GitHub 生态内采集 CC0 曲目）

## 二、打击感优化方案（多方案，建议全做但分批）

### 方案 F1【核心】hitstop 顿帧系统
- **内容**：命中/暴击/击杀瞬间 `Engine.time_scale` 微停帧（命中 0.05s / 暴击 0.1s / Boss 击杀 0.15s），可叠加衰减恢复
- **改**：新增 `scripts/systems/hitstop_controller.gd`（或并入 GM）；weapon/enemy 命中点调用
- **验**：探针断言 time_scale 时序 + 不破坏 600 帧深探（time_scale 恢复）
- **风险**：中（time_scale 影响全局，需护栏防卡死）

### 方案 F2 相机震屏分级
- **内容**：命中（轻）/ 暴击（中）/ 击杀（中）/ Boss 死亡（重）四级震屏，现有 F-03 玩家受伤震屏复用同级框架
- **改**：震屏参数表化（Excel 或常量） + 调用点补全
- **验**：探针白盒直调断言幅度/时长

### 方案 F3 命中反馈叠加层（粒子/残影/数字）
- **内容**：命中火花粒子 + 暴击大数字放大 + 击杀残影/消散特效；复用 `vfx_container`/IconAtlas/VfxPlayer 既有管线（D 阶段特效已收口 `f5cd533`）
- **改**：VfxPlayer 新增命中/暴击/击杀模板；weapon/enemy 死亡点触发
- **验**：day30 特效探针扩展

### 方案 F4 敌人受击僵直/抖动 + 击退分级
- **内容**：受击 0.1s 僵直（打断攻击前摇）+ 抖动 1-2 帧 + 击退力度分级（轻武器无/重武器强）；Boss 免僵直只抖动
- **改**：enemy.gd 受击状态 + enemy_movement.gd 击退参数
- **风险**：中（Boss 动作中断链；需免僵直豁免）

### 方案 F5 音画同步
- **内容**：命中 SFX 延迟≈0（立即）、暴击延迟 +crit 音、击杀 +death 音；空挥不发音（自动射击无空挥概念，普攻由 weapon 触发）；技能释放 + 蓄力感音
- **改**：audio_manager 增加 `play_sfx_delayed` / 命中点串联；SFX_MAP 增补（空挥/暴击/击杀/技能分层）
- **验**：探针断言 SFX 调用时序

## 三、手感优化方案（多方案）

### 方案 H1 移动手感（加速/摩擦/转向）
- **内容**：移动改为「加速-摩擦」曲线（起步加速 + 松键滑行），转向方向插值（非 180° 瞬转）；参数表化
- **改**：player 移动组件 + 输入读取
- **风险**：中（体感回归面大，需 #5 真人逐项确认）

### 方案 H2 攻击节奏反馈（自动射击）
- **内容**：射击命中率反馈 = 弹道命中火花（F3 复用）+ 受击 SFX；武器切换冷却 HUD 图标闪动 + 音
- **改**：HUD 冷却显示 + weapon 命中点

### 方案 H3 技能释放手感
- **内容**：技能释放 0.1s 前摇（红圈警示）+ 释放瞬间 hitstop 微顿 + 专属 SFX（现有 `skill` 音已占位）；位移技能后摇可取消（dash/blink 已有 invulnerable）
- **改**：skill_controller 释放链 + PS-D 位移技能参数

### 方案 H4 数值体感（攻速/移速档位）
- **内容**：攻速/移速非线性档位（低档线性、高档递减收益），避免后期手忙脚乱；配合 Excel 数值表
- **改**：stats 表 + 属性换算（走 Excel 管线，禁手改 JSON）

## 五、红线与护栏（拆解/执行时必须遵守）

1. **本文件仅方案，未拆解前 #3 禁止动工**（沿用 G 系列「文档先行」纪律）。
2. **audio_manager 接口契约**：SFX_MAP/BGM_MAP 键名是探针锚点，新增键只追加不删改；wav 缺资源已零崩溃，替换文件保持同名同格式。

4. **Boss 豁免**：僵直/击退/震屏对 Boss 降级或豁免（BOSS_SKILL_SPEC 免疫表惯例）。
5. **数值改动走 Excel 管线**（H4 等），禁手改 JSON。
6. 采集 CC0 素材：从 GitHub 生态内获取（raw/codeload 可达），**不把外部下载脚本当提交物**；来源标注入库。
7. 每批验收 = 探针 + baseline + #5 真人主观项（手感/听感归 PLAYTEST，不伪装机器 PASS）。
