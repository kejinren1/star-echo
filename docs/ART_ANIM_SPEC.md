## 2. L1 呼吸动画参数（定稿 08-14 · 云霓 96px 范例）

### 2.1 烘焙参数（tools/breath_wave_bake.py）

| 参数 | 值 | 说明 |
|---|---|---|
| 帧数 | 12 | 12 帧 @6fps = 2 秒一个呼吸循环 |
| 播放速度 | 6 fps | 与 player.gd `idle_fps=6.0` 对齐；用户定（1.5s→2s 更舒缓） |
| 波形 | 平滑正弦（行搬移） | 单波从下往上传递，某一时刻只有波峰部位在动 |
| 波长 λ | **192px（2 倍身高）** | 用户定：压缩/拉伸区最平缓，不扭曲（96→160→192 试错后定） |
| 振幅 | **0.6px** | 用户定：0.4 太死、0.8-1.5 脸会被拉长（0.6 若有若无） |
| 脚底冻结 | 5 行（dy=0） | 脚底水平线完全静止（跨帧像素 0 差异） |
| 脚部渐入 | 20px | 脚踝向上振幅线性爬升，防突变 |
| **头部刚性** | 分界线=身体上部 30%（≈颈部） | **分界线以上整体平移、不逐行拉伸**——头发/脸保持一体（头部无关节，长度变化不合理） |
| 分界线过渡带 | 6px lerp | 波浪→刚体平滑衔接，无硬折痕 |

### 2.2 物理逻辑（三段式，用户认可）
- 脚底以下：静止（扎根）
- 身体（脚踝→颈部）：波浪传递（涟漪）
- 头部以上：刚性整体平移（无关节部位不变形）

## 3. 抠底管线（tools/build_anim_sheet.py v4 · 08-14 定稿）

```
帧序列(96px) → detect_bg_color(四边众数) → floodfill(切比雪夫 tol=6，只抠与背景几乎相同的像素)
→ erode_edge_near(距背景 ≤10，2 层：清渐变带/毛刺) → clean_small_blobs_near(<100px 近背景块：清封闭环缝隙)
→ align bottom(脚底锚定) → freeze_bottom(5 行) → 横排 sheet
```

### 3.1 踩坑记录（防再犯）
1. **容差宁小勿大 vs 抠轻了（08-15 用户实证修正）**：tol=28 会抠掉浅色角色主体（若叶睦 54%），但 **tol=8 也会抠轻**（边缘背景残留 20px）——**正确做法：按"角色轮廓是否闭合"选容差**。轮廓闭合（发丝圈能形成说明封闭）→ 连通性保护下容差可加大到 12-18（背景残留 20→6，彩色仅损 4-5px/0.1%）；云霓白底 96px 帧轮廓开放 → 保持 tol=6 + erode/blobs
2. **抠底前必须检测背景色域**：若叶睦背景是浅绿 (222,229,220) 不是白——不检测就按白底调参必翻车
3. **floodfill 只抠连通四边的区域**：角色包围的"封闭环背景缝隙"抠不到 → 需 clean_small_blobs 补 / 或按用户指认精确抠簇（find_clusters 近背景色簇 + 距离匹配）
4. **白色角色 vs 白底同色**：颜色判据物理极限（云霓白衣差 5px 内），接受边缘白被抠，彩色主体 99% 保留
5. **背景与角色同色系时自动抠底无解**（若叶睦案例）→ 见 §4 美术标准，源头规避
6. **发丝圈/闭合缝隙 = 算法物理极限**：720 尺度 floodfill 也进不去（发丝完全闭合）→ 美术标准禁闭合 + 编辑器手工补（perfect-pixels 颜料桶/替换同色）

### 3.2 已知残留（08-14 现状）
- 角色边缘 1-11px 深色碎屑（发丝/衣角尖）可能断开漂浮——96px 放大 2x 可见
- 处理策略：**美术标准源头规避（§4）+ 接受现状**（用户 08-14 拍板："技术水平在这里"）

## 4. 美术生成标准（AI 直出阶段 · 防"辫子断/抠不净"）

> 原则：**让 AI 素材适配管线，而不是让管线迁就 AI 素材**。生成 prompt 必须遵守：

1. **发型规范（硬性）**：避免"大面积散结构头发"——碎发、过细发丝、多股散落发绺、复杂辫梢一律禁止；推荐**紧致发型**（束发/低盘发/单马尾），发辫主体宽 ≥4px（96px 尺度），长度不超出角色身体轮廓
2. **发丝闭合禁令（硬性，08-15 用户拍板）**：**发丝/飘带不得形成闭合圈**（发丝圈住背景会形成抠不掉的封闭环白块，算法物理极限）；悬空发丝末端必须开放
3. **背景规范（硬性）**：背景必须**纯白**（AI 直出白底图），禁止浅绿/浅蓝等可能与角色同色系的底色——若叶睦案例（浅绿底+绿角色）自动抠底物理无解
3. **构图规范**：角色主体占画面 ≥60%；前景占比 <40% 的角色重新构图（denoise 0.6-0.7 抢救，见 docs/art_ai 复盘）
4. **色区规范**：角色大面积主色与背景色差 ≥ 25（切比雪夫），否则抠底误伤
5. **检验**：出图后跑 build_anim_sheet.py，彩色保留率 ≥95% 才算通过；<95% 且非角色问题 → 回炉重生成

## 5. 动画验收标准（每角色交付前）

- [ ] 脚底冻结：底部 5 行像素跨帧差异 = 0
- [ ] 头部刚性：分界线以上整体平移（无头发/脸分离）
- [ ] 抠底干净：无背景残留块；彩色保留率 ≥95%
- [ ] 帧率 6fps、循环首尾无缝
- [ ] 单帧尺寸 ≤96px、透明 PNG、走 COLOR_DICT 色号体系（如需量化）

## 6. L2 骨架工作流（SOP 简版 · 待云服务器）

1. 用户画/描述动作 → 骨架（OpenPose）→ 确认
2. aziibpixelmix + 骨架 → 生成 2-4 张关键姿势帧（768 直出 → perfectPixel 96px）
3. build_anim_sheet.py（§3 管线）→ 引擎 SpriteFrameFactory 挂接
4. 一致性由"锚点对齐 + 引擎补间"保证，不依赖视频模型

## 7. 眨眼（降级可选）

需一次性眼睛锚点标注（ART/eye_anchors.json：左右眼 bbox + 肤色/眼线色号）+ 程序合成闭眼帧（像素替换+眼线，非 AI 生成）。64px 实际显示收益低，优先级最低，锚点流程建立后顺手做。
