## 1. 背景与决策记录（用户原话要点）

1. **多技能位**（拍板 D1）："多技能这个思路是比较好的，Build 的深度最高"——技能位本质是"技能槽 + 键位绑定"，**用户已拍板多技能位**；键位**弃用数字键**（"空格 + 数字 1/2 太别扭，操作不舒服"）→ **空格 + 鼠标左键 + 鼠标右键**。
2. **技能来源**（拍板方向）：局外养成升级给技能（"加到后面可以给一个技能，鼓励继续游玩"）+ 精英怪/路中小 Boss 提供更多技能来源（"只有两个大 Boss 有点少"）。
3. **章节化关卡**（拍板 D3）：不再 1-15 层线性，分章节；**4 章**；**第 1 章末尾无 Boss**，改为**事件（休息 + 奖励）**。
4. **定位权衡**（用户抛出的核心问题，§3 定案）："Boss 技能是强玩法之一，还是彩蛋性质？如果 Boss 固定、掉的技能固定、影响力强 → 玩法固化，到点解锁，没有肉鸽感。"
5. **位移技能**（拍板 D2 方向）："可以开发一些除了伤害数值和状态的技能，比方说位移技能——人物只有两三个技能时，面对高难 Boss 有几种解法：输出技能灌伤害 / 灵活走位。" **无敌帧不写死，作为技能效果的一部分动态调整。**
6. **掉落物角色差异化**（拍板 D7，重大变更）："所有人都放同一个技能，感觉有点违和。改成 **Boss 掉落物品，物品在不同角色身上产生不同效果**——法师原本放火球，Boss 技能到他身上变成放光柱；剑士（星刃）改成向前挥一刀剑气爆发。" 数值现在不重要，半径可以小一点。
7. **附注（用户吐槽）**：剑士星刃主动技能"挺垃圾的" → 登记反馈（见 §10），D7 剑气方案顺带替换。

## 3. 定位定案：调味层 · 随机战利品 · 不碰核心数值

> 用户关切："Boss 固定、掉的技能固定、影响力强 → 玩法固化"。**解法不是弱化技能，而是随机化获得 + 控制影响力**。

- **获得随机化**：技能不进"必得清单"，进**掉落池**。击败精英/章 Boss → 从技能池随机抽 3 候选 → 玩家三选一装配（交互复用升级面板）。每局掉什么、掉几个、装不装全是变量。
- **影响力中等**：技能伤害挂玩家属性缩放 + 长 CD → 关键时刻的质变道具，不是每秒输出主力。**主力永远是武器 Build（6 槽+进化）与被动组合**；技能是第三层调味。
- **局外等级保底**（D6）：角色升到指定等级解锁"基础技能包"或第 3 槽位——**门槛动态可配（Excel 表配置，不写死）**，上线后按实际升级节奏再调。

## 4. 技能位与键位（D1 拍板 · 键位有细节建议见 §4.2）

- **3 槽**：空格 / 鼠标左键 / 鼠标右键 各绑一个技能，独立 CD，HUD 技能栏 3 格（各转各的 CD 圈）。
- **数据**：`characters.json` 的 `skill` 字段 → `skills` 数组（默认技能为"初始装备"，仍保留英雄特色）。
- **局内替换**：拾取掉落 → 三选一装配（或替换当前选中槽）→ 可换可不换。
- **实现量级**：skill_controller 从"单技能 match"改"技能列表 + 键位路由"；HUD 技能栏 1→3 格。**一个回合量级，非重构**。

### 4.1 键位方案（用户拍板：空格 + 鼠标左键 + 鼠标右键）

| 键位 | 定位建议 | 理由 |
|------|---------|------|
| 鼠标左键 | **指向性技能**（点击位置施放：放圈/指向发射） | 鼠标天然是"指哪打哪"的设备，操作上限最高；暗黑/POE 左键技能是成熟范式 |
| 鼠标右键 | 自动索敌/自施放技能 | 常见"主输出位"；右键按下即放，不打断移动 |
| 空格 | 英雄默认技能（初始装备） | 拇指位，与 WASD 同手不打断移动 |

**市面方案参考**：① 暗黑破坏神/POE——左键+右键各绑技能 + 数字键扩展（证明"鼠标双键绑技能"成熟）；② MOBA（LOL）——QWER 四技能 + 鼠标操作，但移动在右键，与本作不同构；③ 吸血鬼幸存者/Brotato 类——攻击自动、无主动技能位，操作极简（本作引入主动技能已是超配）。**本作特殊性：移动=WASD 键盘、攻击=自动、鼠标局内空闲** → 鼠标左右键绑技能是最自然的（手不离开键鼠、不打断移动），优于数字键（左手离开 WASD 够键，打断移动）。

**实现注意（拆解必含）**：
- 局内 UI（暂停菜单/背包/商店）用鼠标点按钮时，**技能键不得触发**——Godot UI Control 消费输入或 pause 时禁用 `_unhandled_input` 技能路由。
- 指向性技能需要"点击地面施放"：`InputEventMouseButton` 转世界坐标，复用现有目标点逻辑（route/弹道）。
- 手柄支持后补（Steam PC 优先，不影响本期）。

### 4.2 无敌帧不写死（D2 拍板）

无敌帧**不是技能字段硬编码**，而是**效果表（elements/effect 表）的一种效果类型**（如 `type=invulnerable` + `duration` 参数），随技能数据动态调整（BOSS_SKILL_SPEC §4.3 效果表升级后自然承载）。建议默认值仅作手感起点：dash 0.3s / blink 0.1s / leap 落地前 0.2s——**数值归数值，可调**。

## 5. 技能类型矩阵（玩家侧）

| 类 | 行为类型 | 例 | 解法方向 |
|----|---------|----|---------|
| 伤害 | circle / fan / beam / charge | 爆裂圈 · 扇形扫 · 光柱 · 蓄力 | 输出流（DPS 检查） |
| 召唤 | spawn | 炮台 · 召唤兽 | 持续输出 / 嘲讽位 |
| 增益防护 | buff / shield | 庇护 · 圣盾 · 加攻 | 坦护流（资源换容错） |
| **位移（新增）** | **dash / blink / leap** | 冲刺 · 闪现 · 跃击 | **机动流（全躲机制）** |

> 面对高难 Boss 的**三条解法分叉**（用户原话延伸）：输出流灌伤害 / 机动流靠位移全躲 / 坦护流硬吃。三条路 = 三种 Build 方向 = Boss 战不固化。3 槽组合（输出+机动 / 输出+坦 / 全输出…）+ 每局掉落随机 = 组合策略随机。

## 6. 位移型技能专项（D2 拍板方向）

### 6.1 为什么值得做

自动射击游戏玩家操作面只有"移动 + 技能"，位移技能把"走位"从被动微操升级为**主动资源管理**（CD 管理 + 时机决策）。同时直接支撑 §5 的"机动流"解法：Boss 预警圈来了，位移 = 一次"逃生距离压缩"，是玩家侧主动降低难度的技术性工具。

### 6.2 三种行为类型

| 类型 | 表现 | 特点 | 代价 |
|------|------|------|------|
| dash 冲刺 | 沿移动方向快速位移一段 | 手感最直接、最通用 | 可被连续预判，CD 中 |
| blink 闪现 | 瞬移到目标点（可穿怪） | 出圈神器，机制解法核心 | CD 最长 |
| leap 跃击 | 起跳砸向目标点 | 位移 + 落点小范围伤害/击退（位移与输出结合） | 有落地后摇 |

### 6.3 关键参数（技能表字段，均走数据驱动）

- `distance` 位移距离 / `duration` 位移时长（dash 快移 vs blink 瞬移）
- **`effects` 列表含 `invulnerable` 效果（D2：不写死，随数据调）**
- `cooldown`：8-12s（防"变成第二移动键"，保持决策型而非无脑滚）
- `aftercast` 后摇硬直 0.2s（同理防连用）
- 可选 `leave_damage`：路径/落点伤害（leap 用，伤害挂玩家属性缩放）

### 6.4 与公平底线公式的关系

BOSS_SKILL_SPEC §2.2：`t_w > 2r/v + 0.4s`（纯走位可躲的底线）。位移技让玩家把 `2r/v` 的逃生距离压缩为一次位移 → **玩家侧主动降难度，不破坏底线，反而让"躲"更有技术含量**（算 CD、算时机、算落点）。

## 7. 技能来源与掉落规则（D4/D5 拍板）

- **精英怪**（每章 2-3 个）：掉**低阶技能**（技能池首批 6-10 个：圈/扇形/横扫/激光/冲刺/闪现/护盾…）。
  - **掉落概率（D4 拍板）**：参考桌游"常规动作成功率"口径——**80% 触发技能三选一**，20% 给替代奖励（金币/属性碎片等）。数值可配。
- **章节 Boss**：**招牌技必掉**（D5 拍板，该 Boss 用过的招式 = 教学闭环）+ 随机池。
- **拾取交互**：三选一装配（复用升级面板交互范式）。
- **技能池目标 ≥12**：池够大后每局随机出池 → 组合爆炸。

## 8. 章节化关卡（D3 拍板：4 章 · 第 1 章无 Boss）

- **现状**：routes.json 15 层线性 + boss_layers [9,14]（第 10/15 层 Boss）= 已是"两章"雏形。
- **目标：4 章**，`routes.json` 加 `chapter` 字段（chapter_id / 主题怪池 / 精英位 / 章末节点类型）。
- **第 1 章末尾无 Boss（用户拍板）**：章末节点 = **事件（休息 + 奖励）**——新手暖手章，先给节奏缓冲再面对第一个 Boss。
- **层数划分建议**（复用现有 15 层，可调）：章 1 层 1-3（章末事件）/ 章 2 层 4-7（Boss A「爆裂圈」）/ 章 3 层 8-11（Boss B「腐蚀圈」）/ 章 4 层 12-15（Boss C 最终，新增 1 个 Boss）。
- **节奏**：章间可插整备节点（商店/回血/事件）做呼吸感；每章 2-3 精英位 = 技能掉落主来源。
- **大地图兼容**：G-R1 节点地图加章界横幅/分隔线（数据驱动，不动画布架构）。

## 9. 掉落物角色差异化（D7 拍板 · 重大变更 · 本节为本规格核心设计）

> 用户原话："所有人都放同一个技能，感觉有点违和。要么就改成 Boss 会掉落物品，然后这些物品可以在不同人的身上产生不同的效果。"（例：法师火球 → 光柱；剑士星刃 → 剑气爆发）

### 9.1 设计含义

- **掉落物 = 中立"技能核心/秘技残片"**（物品级战利品），**效果 = 按角色映射为专属技能变体**。
- 同一掉落物，不同角色佩戴 = 不同技能（同类型不同参数，或不同类型）：法师放光柱、剑士劈剑气、召唤师变召唤、奶妈变守护——**角色特色不被稀释，掉落物仍随机**。
- 好处：① 一个掉落物 = 4 种体验 → **鼓励多角色游玩**（与角色培养/图鉴局外系统联动）；② 保持执行器中立（变体仍走 SkillExecutor + apply_effect）；③ 掉落随机性不变，肉鸽感保住。

### 9.2 数据实现（供 #2 拆解参考）

- 新表 `skill_relics`（Excel sheet → JSON）：`id / name / desc / per_character: {char_id: {type, params…}}`——每个角色一行变体配置（type 引用 SkillExecutor 行为类型，params 覆盖技能参数）。
- 掉落 → 装配进技能槽时，**DataLoader 按当前角色查 `per_character[char_id]`** 得到实际技能；无该角色条目则走通用兜底（或不可用）。
- 玩家版参数（§9.3 默认值）作为变体配置的一部分，**全部数据驱动可调**。

### 9.3 玩家版数值默认值（D7：数值现在不重要，先定口径）

| 参数 | 默认口径 |
|------|---------|
| telegraph 预警 | 归零或 0.1s（玩家技能不用读秒） |
| radius 半径 | ×0.6 左右（用户拍板"半径可以小一点"） |
| cooldown | ×1.5-2（8-12s 基准） |
| damage | **挂玩家属性缩放**（`scaling_attr`，吃武器/被动/属性加成，不脱 Build） |

### 9.4 剑士星刃替换（用户吐槽登记）

用户反馈："星刃技能挺垃圾的" → 登记为**玩家反馈项**（PLAYTEST 追踪区）：剑士默认主动技能体验差。**D7 落地时顺带替换**：星刃 → 剑气爆发（向前挥出扇形/贯穿剑气，一次爆发伤害）——作为剑士对"技能核心"的变体形态之一（或直接重做默认技能，拆解时定）。
