## 二、成功经验（可复用的资产）

1. **SSH_ASKPASS 非交互登录**（Windows 无 sshpass/expect）：`SSH_PASS=pw SSH_ASKPASS=askpass.sh SSH_ASKPASS_REQUIRE=force ssh ...`——askpass.sh 只 `echo $SSH_PASS`。密码试错顺序：先试用户最后给的变体。
2. **API token 从日志白拿**：云厂商镜像日志（`/root/ComfyUI/user/comfyui_8001.log`）里直接搜 `token=`，比猜认证方式快得多。
3. **模型缺失用替代不阻塞**：无 Animagine XL → 用 `Neta Art XL V2`（SDXL 二次元，效果 70 分）；无 Pixel-Art-XL LoRA → 用 `aziibpixelmix_v10`（SD1.5 像素模型）顶替"像素语言"职责——**技术书"Pixel Art 转换"步骤用像素模型 img2img 实现，不依赖 LoRA**。
4. **C+B 组合管线**（本次最大成果）：C 重构母图（IPAdapter 0.8 管"这是谁"）+ 像素模型 img2img denoise 0.4（管"怎么画"）→ 128/64/32 → COLOR_DICT 量化。像素化与降采样严格两步（技术书九节铁律）。
5. **低分角色用 denoise 抢救**：前景占比低的角色（<40%）提 denoise 0.6-0.7 重新构图，占比可拉到 70-90%；**d06 全局首选，个别角色吃 d07**。
6. **subagent 分工模式**：重活（批量生成）派 general-purpose agent + 自包含 HANDBOOK，主代理只做决策与验收；实测 12 角色全管线 4 分钟跑完。
7. **幂等管线脚本**：run_cb_pipeline.py 已有母图自动跳过重构（--skip-c），断点续跑不重复烧钱。
8. **量化指标辅助评分**：32px 前景占比 / 独特色数 / 量化覆盖率 可客观推导质量分，先机器筛后人工抽检。
