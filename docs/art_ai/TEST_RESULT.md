## 二、A vs B 路线对比

| 维度 | A：传统缩放基线 | B：AI 像素化主路线（本轮） | 结论 |
|---|---|---|---|
| 流程 | 原图 → nearest/管线降采样 → 32/64 | 原图 → AI 像素模型(denoise 0.45) → 512 → nearest 128/64/32 | B 多一步 AI 理解，重构造像素语言 |
| 512/768 质量 | 无 AI 阶段 | 512×512 像素风直出，色数 2-6 万，像素语言自然无糊边 | B 胜（A 无对应产物） |
| 64px 表现 | A_pipeline 抠底量化后仅 12-19 色，色块少而平 | 量化后 28-79 色，保留中间调与服装层次 | B 胜（色阶丰富） |
| 32px 辨识度 | nearest 直接缩放，锯齿重、色彩噪点多（A32 色 157-331 含大量插值伪色） | AI 像素色块规整，量化后贴游戏色板 | B 略胜（色块语言更像素化） |
| 调色板贴合 | A 未强制量化到 COLOR_DICT | B 全部量化到 163 色游戏板，覆盖率 100% | B 胜 |
| 成本 | 本地秒级 | 云 GPU 每张约 1 分钟 | B 慢（可接受，批量自动跑） |
| 一致性 | 与原图像素级一致 | seed 固定 12345，同批风格稳定 | B 略胜（AI 会重构，细节与原图有差异） |
| 风险 | 无 | 小尺寸（32px）前景占比差异大（22%-97%），部分角色偏小 | B 需对低占比角色重构图 |

## 三、结论

1. **AI 像素化值得做**：B 路线在 64px 量化后保留 28-79 个游戏色阶，明显优于 A 基线（12-19 色），且 32px 下像素语言更规整、直接落进 COLOR_DICT 色板（覆盖率 100%），省去后处理调色步骤。
2. **模型替代成立**：服务器无 Pixel LoRA，用 aziibpixelmix_v10（SD1.5 像素风模型）+ denoise 0.45 可达到像素化效果，不必依赖 LoRA 栈。
3. **留观清单**：陈（37%）、维什戴尔（33%）、龙舌兰（22%）32px 前景占比过低，建议复跑时提高 denoise 至 0.5 或调整构图；若叶睦/傀影/安洁莉娜为本次最佳样本。
4. **生产建议**：B 路线可批量落地，12 角色四级图 + 量化 sprite 已归档 `output_abc/B_pixel/<角色名>/`。

## 四、遗留问题

- 32px 前景占比与角色原始立绘占幅强相关，AI 像素化不会自动放大角色——低占比角色需单独构图或裁切处理。
- img2sprite.py 读取 COLOR_DICT 需扁平化 JSON（嵌套 meta/colors 结构不支持），已生成 `B_pixel/_palette_flat.json` 备用。
- 评分基于客观指标推导，最终上线前建议人工抽检低分角色（龙舌兰 / 陈 / 维什戴尔）。
