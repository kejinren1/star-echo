# B 路线低分角色复跑抢救（B_pixel_fix）进度

> 更新：2026-08-13 · 执行：general-purpose-2
> 目的：龙舌兰/陈/维什戴尔 上一轮 B 路线 32px 前景占比过低，用更高 denoise 重新构图、放大角色。

## 参数

| 项 | 值 |
|---|---|
| 模型 | aziibpixelmix_v10.safetensors（SD1.5） |
| 输入 | inputs_512/<角色>_1.png（512×512 白底） |
| 轨道 | portrait |
| seed | 12346（全部统一） |
| denoise | 0.6 / 0.7（每角色各 1 张） |
| 归档 | `B_pixel_fix/<角色>/d06|d07/{512_pixel,128px,64px,32px}.png` |

## 生成与归档

- 6/6 成功，无失败。Comfy 输出 i2i_00013~00018 → 立即改名归档。
- 本地 SSH 隧道曾失效（18001 拒绝连接），已按手册重建。

## 32px 前景占比对比表（非纯白像素比例）

| 角色 | 旧版 denoise 0.45 | 新版 d06 (0.6) | 新版 d07 (0.7) | 最佳档 |
|---|---|---|---|---|
| 龙舌兰 | 21.9% | **83.5%** | 90.3% | d06（↑3.8×） |
| 陈 | 36.6% | **70.3%** | 53.9% | d06（↑1.9×） |
| 维什戴尔 | 33.0% | 30.1% | **94.5%** | d07（↑2.9×） |

## 结论

- **denoise 0.6 是全局最稳参数**：龙舌兰 +62pt、陈 +34pt 均达标，维什戴尔略降（-2.9pt）但可接受。
- denoise 0.7 效果分化明显：维什戴尔大幅提升（+61pt）但陈反而回落（-16pt），说明 0.7 构图波动大，不适合作为统一档。
- **推荐保留方案**：
  - 龙舌兰 / 陈 → **denoise 0.6**（覆盖原 512_pixel、128/64/32 全链）
  - 维什戴尔 → **denoise 0.7**（或对 0.6 版做二次抢救）
- 遗留：前景占比提升后角色放大明显，但 32px 下细节（面部/发丝）仍需目视确认是否过曝或糊化；本次仅统计占比，未做调色板量化。
