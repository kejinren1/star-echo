### 二、【需人工试玩】标记项

#### H-01 · 游戏手感 / 操作反馈【需人工试玩】
- **关注点**：移动跟手度、自动攻击释放节奏、主动技能（冷却/资源）释放反馈、命中顿帧 / 受击反馈是否到位。
- **试玩方法**：用每个英雄各跑 1 局前 3 波；刻意频繁移动 + 偶尔停手，记录「攻击是否自动锁定最近敌人」「主动技能冷却提示是否清晰」「受击是否有明确反馈」。
- **机器可验证 counterpart**：无（手感属主观）；#4 仅能监控「主动技能是否有对应 CD/资源字段」等结构存在，不评价体验。

#### H-02 · 难度曲线体感【需人工试玩】
- **关注点**：前 / 中 / 后期压力是否平滑，是否存在「无聊→暴毙」断层；Boss（腐化巨树）两阶段切换是否自然。
- **试玩方法**：完整跑通 1 张地图（10 节点 + Boss），按阶段记录「第 N 波开始觉得吃力」「Boss 一阶段→二阶段是否突然劝退」。
- **机器可验证 counterpart**：waves.json 波次数量（20）、enemies.json scaling（5 档）结构存在——曲线「好不好玩」需人。

#### H-03 · 数值是否「好玩」【需人工试玩】
- **关注点**：武器 / 被动 / 属性组合是否产生有趣 Build；进化武器（炎星术 + 烈焰核心 → 炎星陨落）是否有质变爽感；是否存在「唯一解」或「废数值」。
- **试玩方法**：刻意构筑 3 套极端 Build（纯攻速 / 纯暴击 / 纯吸血），各跑 1 局，记录「哪套有明显正/负反馈」「进化前后体感差距」。
- **机器可验证 counterpart**：stats.json 15 条公式存在、items.json 47 条被动存在——数量在，组合「有趣」需人。

#### H-04 · UI/UX 顺畅度【需人工试玩】
- **关注点**：角色选择 → 进局 → 商店 → 事件 → 结算的流转是否顺畅；HUD（血/属性/波次）是否一眼可读；文本事件（10 个）阅读体验。
- **试玩方法**：走通「选英雄 → 事件节点 → 商店 → Boss 结算」全流程，记录「在哪一步卡顿 / 找不到按钮 / 信息过载」。
- **机器可验证 counterpart**：无头 baseline 只能验证场景可加载（_ready 通过），不能验证交互流顺畅度。

#### H-05 · 视觉 / 听觉主观感受【需人工试玩】
