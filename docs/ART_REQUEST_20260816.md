## 五、交付规范（重要）

1. **透明 PNG 直发**（最省事）：抠好底、白底镂空的透明 PNG，命名带角色/动作/帧序（如 `noah_walk_01.png` 或整条 sheet `noah_walk.png`）。
2. **白底 JPG 原图**（也可）：放 `ART/RAW/`，由 `tools/img2sprite.py` 自动抠底→降采样→量化（艾琳 28 JPG 先例，效果已验证）。
3. **sheet 布局约定**：横排、正方形帧、帧数=宽÷高（如 256×64 = 4 帧×64px），角色 64px / 普通敌 48px / 精英 64px / Boss 128px / 图标 32px / 特效 64px。
4. **色板**：尽量贴近游戏调色板 `ART/COLOR_DICT.json`（163 色）；偏差 ≤12 会自动量化，偏差大颜色会跳。
5. **风格参考**：角色要素定稿表 `docs/art_ai/角色要素定稿表_20260816.md`（4 主角 + 8 Boss 全要素）；现有资产可看 `assets/sprites/` 同类做参考。
6. **不确定就问**：帧数、尺寸、风格拿不准时先发 1 帧样图确认，再批量产。
