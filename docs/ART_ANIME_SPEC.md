> **不覆盖** `ART_STYLE.md` 的任何技术基底，仅在其上追加方向层。
>
> **⚠️ v2 对齐注记（2026-08-06）**：`ART_STYLE.md` 已升级 v2 —— 精灵基准 **32px → 64px**（角色 64×64 / 敌人 48×48~64×64 / Boss 128×128）、色数 **32 色硬约束 → 216 色上限·字典登记制**（锚点色板 32 色硬锚点 + 容差归并 ΔRGB≤12 + 色号编码 + 透明键协议）。本文档内所有「继承 ART_STYLE 技术基底」的表述（32px 网格 / Indexed 32 色 / 1px 描边）一律以 **`ART_STYLE.md` v2** 为准；文中已生成的旧规格产物（如 elin_idle.png 4 帧 128×32）为 v2 升级前记录，**新资产统一按 v2 规格生产**。

## 一、定位：Anime 像素 · 高饱和幻想 · 华丽特效

### 与 ART_STYLE.md 的关系

| 维度 | ART_STYLE.md（技术基底） | 本文档（方向层） |
|------|--------------------------|------------------|
| 视口 / 缩放 | 640×360 / integer / Nearest | **继承不变** |
| 网格密度 | 32px 基准 | **继承不变** |
| 调色板 | 32 色 Indexed | **继承不变** |
| 描边 | 1px 深色（#0d0d12） | **继承不变** |
| 风格关键词 | 暗色像素 · 高对比 · 硬朗轮廓 · 霓虹点缀 | **升级为** Anime 像素 · 高饱和幻想 · 华丽特效 |
| 角色设计 | 战士/游侠/法师（通用模板） | **替换为** 艾琳/诺亚/莱恩（二次元立绘语言） |
| 特效 | 极短帧数、粒子化、颜色编码 | **强化为** 华丽粒子层次 + 霓虹光源感 + 进化大招表现力 |

### 核心设计原则

1. **二次元立绘语言 × 像素实现**：角色表情/姿态/发型具有二次元辨识度（大眼比例、发型剪影、装备配件），但全部以 32×32 像素 Sprite 实现。
2. **高饱和幻想色**：在 32 色调色板内优先使用霓虹特效组（#00f5ff / #ff00ff / #fffd00 / #39ff14）作为技能光源色；角色主色取自角色与敌人组的高饱和色。
3. **华丽技能特效**：VFX 不再是"简洁命中粒子"，而是有层次、有节奏、有进化表现的视觉演出。
4. **科幻×幻想融合**：武器/配件带微弱科技线条感（诺亚炮台/莱恩星刃），魔法效果保留幻想光晕（艾琳火焰）。

## 四、华丽技能特效需求（VFX Spec）

> 在 ART_STYLE.md 第六章基础上，**强化**为"华丽"层级。
> 所有 VFX 仍遵守：4-8 帧循环、32 色调色板、Nearest 过滤、极低性能开销。

### 4.1 特效分层模型

每个华丽 VFX 由 **3 层** 组成（Godot 中可用 3 个重叠 GPUParticles2D 或 AnimatedSprite2D 实现）：

| 层 | 名称 | 内容 | 生命周期 |
|----|------|------|----------|
| L1 | 核心（Core） | 主体形态（火球本体/召唤阵/星刃） | 全程可见 |
| L2 | 粒子（Particles） | 3-8 个小碎片/火花/能量点飞散 | 后半段出现并消散 |
| L3 | 光晕（Glow/Halo） | 1-2 帧的霓虹色边缘扩展/收缩 | 首尾各 1-2 帧 |

### 4.2 各英雄签名技能 VFX

#### 艾琳 — 火球 (Fireball)

| 层 | 表现 | 配色 | 帧数 | 尺寸 |
|----|------|------|------|------|
| L1 核心 | 圆形火球，内亮外暗渐变 | 中心 #fffd00 → 边缘 #ff5e00 → #e94560 | 4 | 16×16 |
| L2 粒子 | 4-6 个橙色小火星拖尾 | #ff5e00 / #ff6b35 | 4 | 8×8 每个 |
| L3 光晕 | 出现时 1 帧 #fffd00 放射状光芒 | #fffd00 | 1 | 24×24 |

**弹幕拖尾**：火球移动时每 2 帧留下一个 8×8 的 #ff5e00 半透明残影（alpha 渐隐）。

#### 诺亚 — 召唤炮台 (Summon Turret)

| 层 | 表现 | 配色 | 帧数 | 尺寸 |
|----|------|------|------|------|
| L1 核心 | 方形炮台底座 + 炮管 | 底座 #7a7a8f / 炮管 #4e89de | 4 | 24×24 |
| L2 粒子 | 发射时 3-4 条青色短线（弹道） | #00f5ff | 2 | 16×4 |
| L3 光晕 | 召唤完成 1 帧 #00f5ff 六边形阵纹 | #00f5ff | 1 | 32×32 |

**待机动画**：炮台 idle 时炮管微转（4 帧 ±2px 摇摆）；能量核心 #00f5ff 呼吸明暗。

#### 莱恩 — 环绕星刃 (Orbit Star Blade)

| 层 | 表现 | 配色 | 帧数 | 尺寸 |
|----|------|------|------|------|
| L1 核心 | 2-3 把小型弧形刃围绕角色旋转 | 刃身 #9d4edd / 刃缘 #00f5ff | 4 | 12×12 每把 |
| L2 粒子 | 刃划过空气留下的青色弧线残影 | #00f5ff 半透明 | 2 | 弧形约 16×16 |
| L3 光晕 | 暴击命中时 1 帧 #b026ff 紫色十字闪光 | #b026ff | 1 | 20×20 |

**旋转逻辑**：非纯 Sprite 动画——由代码控制角度旋转（GPUParticles2D 或围绕父节点的子节点），Sprite 仅提供单帧刃图形。

## 五、数据驱动对接（给 w1-code 的接口约定）

### characters.json 新增字段建议

3 英雄接入 `data/characters.json` 时，除现有字段外建议新增：

```json
{
  "id": "elin",
  "name": "艾琳",
  "sprite": "res://assets/sprites/characters/elin_idle.png",
  "walk_sprite": "res://assets/sprites/characters/elin_walk.png",
  "portrait": "res://assets/sprites/characters/elin_portrait.png",
  "frames": 4,
  "walk_frames": 6,
  "fps": 6,
  "walk_fps": 10,
  "palette_variant": "fire",
  "vfx_theme": "fire"
}
```

| 新增字段 | 类型 | 说明 |
|----------|------|------|
| `walk_sprite` | string | 行走动画帧 strip 路径 |
| `portrait` | string | 立绘占位路径（角色选择 UI 用） |
| `walk_frames` | int | 行走帧数 |
| `walk_fps` | int | 行走帧率 |
| `palette_variant` | string | 色系标识（fire / tech / star），用于换色/特效匹配 |
| `vfx_theme` | string | 特效主题（fire / summon / blade），VFX 系统据此选择粒子配色 |

## 六、制作工具链与工作流

### 推荐工具（与 ART_STYLE.md 第十章一致）

- **主力**：Aseprite（动画/调色板/帧 strip 一条龙）
- **验证**：Godot 4.3 内预览（AnimatedSprite2D + SpriteFrames）
- **调色板文件**：基于本文档第二章 32 色列表生成 `.aseprite palette` 或 `.gpl` 格式
- **批量占位**：Python Pillow 脚本（本冲刺已提供 `gen_hero_placeholder.py` 可复用）

### 正式美术制作流程

1. 加载 32 色调色板到 Aseprite
2. 参照第二节「三英雄视觉语言」绘制 **第 1 帧 idle 静态稿**
3. 团队审查确认方向（截图发给 team-lead）
4. 基于 static frame 制作 idle 4 帧 / walk 6 帧
5. 导出横向帧 strip PNG（Indexed 32 色，索引 0 透明）
6. 放入 `assets/sprites/characters/`
7. Godot 中配置 SpriteFrames 并预览
8. 提交 PR 供 w5-qa 视觉验收
