## 一、世界观

### 1.1 星骸（Star Echo / ステラ・レリック）

近未来，人类在轨道外缘捕获到一个体积超过山脉的物体。它不发光、不辐射、不回应任何频段，观测组按惯例把它归档为「大型生命遗迹」，代号 **星骸**。

三件事很快推翻了「遗迹」这个词：

1. **它改写物质规则。** 星骸内部的物理常数存在局部漂移——同一把枪在不同腔室的弹道、燃烧值、乃至金属疲劳曲线都不同。人类学会了利用这种漂移：把「规则」当作可携带的资源带出来，这就是武器进化与遗物的来源。
2. **它持续产出异变生命。** 星骸不停地"长"出新的生物。它们没有繁殖谱系、没有幼年期、没有天敌，却会模仿——模仿地形、模仿设备、**模仿闯进来的人类**。
3. **它有心跳。** 深层探测记录到间隔 4.2 秒的周期性收缩。医学组做了比对：那是人在睡梦中即将翻身之前，心率变化的曲线。

**核心悬念（全局暗线）：星骸不是死亡的遗迹，它正在苏醒。**
人类这些年从它身上挖走的一切——力量、结晶、规则——都可能只是它睡着时没管的事。

> 叙事纪律：这条暗线**永远不要在文本里点破**。只允许通过三种方式渗透——心跳/呼吸/体温这类**活体隐喻**、异变生命越来越像人的**模仿行为**、以及前辈探索者留下的**未讲完的记录**。玩家应该是自己"发现"这件事，而不是被告知。

### 1.2 回响者联盟（The Echoers）

一个跨国联合体，唯一职能是进入星骸、带回可用的东西。

- **名字的由来**：第一批探索者发现，越是主动与星骸"共振"的人，越能吸收它的力量——代价是身体开始被改写。他们把自己称为「回响者」：**发出去的是人声，回来的已经不完全是了。**
- **第一句呼号**（联盟仪式性开场白，会在多处复现）：
  > 「这里是回响者，我们为理解而来。」
  这句话被异变生命学了去，在 `signal_choir` 事件中被重复六百次——这是全局最重要的伏笔之一。
- **方舟基地（The Ark）**：星骸外缘的前进基地，也是局外养成的载体。研究系统、角色培养、剧情解锁全部发生在这里。基地的官方口径永远是「勘探作业」，从不使用「战争」或「入侵」这两个词。
- **组织的道德灰度**：联盟守则第九条禁止采集活性星骸组织，但联盟自身的研究系统正建立在违规样本上。**基地的温暖与它的伪善要同时存在**——这是本作的冷峻底色所在，不要把联盟写成纯粹的好人，也不要写成阴谋组织。

### 1.3 异变生命（The Mimics）

星骸产出的生物统称。设计上的关键不是「怪物」，而是 **「未完成的学习者」**：

- 早期形态：只模仿形状（像石头、像管道、像倒下的装甲）。
- 中期形态：模仿行为（排队、传递物品、围成环）。
- 后期形态：**模仿人类的情感表达**——练习人类的语调、抱着死者的水壶、对着水面里的你笑。

它们大部分时候仍然要杀，玩家仍然要割草。但**每隔一段时间必须让玩家迟疑一次**——`mutant_child`、`signal_choir` 这类事件的作用就是在爽感之间插入一根刺。

### 1.4 主题关键词

`遗迹` · `回响` · `异变` · `苏醒` · `探索者` · `方舟`

## 二、三英雄背景

> 三人是同一支小队。设计原则：**三人对"星骸是什么"持三种互斥的答案**，所以他们的台词天然构成三角对话，任何事件都能从三个角度切入。

### 2.1 炎术师 · 艾琳（Elin） — Mage

| 项 | 设定 |
|---|---|
| 签名武器 | 炎星术（进化：炎星陨落） |
| 主动技能 | 火球 |
| 一句话 | 用最热的东西，去焐一个不知道是不是活的东西。 |

**背景**：联盟第三代回响者，共鸣适性历史最高值，也因此是被改写得最深的人。她的火焰不是化学燃烧，而是把星骸的规则漂移强行拉到自己身上的结果——每释放一次，她的体温就更接近星骸腔体的温度一次。

**她的答案**：星骸是活的，而且**孤独**。艾琳是队里唯一会对着遗迹说话的人，会在事件里问出那些不该问的问题（「它在哄自己睡觉？还是在哄我们？」）。她共情，但不软弱——她清楚自己在被同化，只是认为"理解一个东西，本来就要付出变成它一点的代价"。

**声音**：轻、快、爱用反问句和自嘲。轻小说女主的语感，但每隔几句会漏出一句非常冷的判断。

### 2.2 机械师 · 诺亚（Noa） — Summoner

| 项 | 设定 |
|---|---|
| 签名武器 | 自动炮台（机械核心遗物专精） |
| 主动技能 | 召唤炮台 |
| 一句话 | 我不需要理解它。我只需要知道它的账怎么算。 |

**背景**：联盟军械与结构物工程师，拒绝接受任何共鸣改造——全身上下没有一处星骸组织，这在回响者里近乎异类。他靠机械替代一切：炮台替他站前排，无人机替他侦察。有人说他怕被改写，他自己的说法是「我只是不想签一份看不懂的合同」。

**他的答案**：星骸是一套**系统**，是账本，是可以被拆解和结算的东西。所以在 `tithe_interface` 事件里，看穿"这不是机器，是账本"的人是他。他的冷峻不是无情，恰恰相反——他是三人中唯一一直在计算"我们还剩多少人可以赔进去"的人。

**声音**：短句、术语、拒绝抒情。冷幽默。越是关心，说得越像技术报告。

### 2.3 剑士 · 莱恩（Ryn） — Melee

| 项 | 设定 |
|---|---|
| 签名武器 | 星刃（环绕型近战） |
| 主动技能 | 环绕星刃 |
| 一句话 | 想不明白的东西，先砍开看看内部结构。 |

**背景**：出身第七勘探队——**三年前全队失联，只有他一个人走出来**，而他对那 40 小时没有任何记忆。他的星刃是用队友装甲上的星骸化残片重铸的，因此这把刀能斩开某些"规则"，也因此它偶尔会自己发热。

**他的答案**：星骸是**敌人**，理由不需要更复杂。但这个答案在整局中最不稳定——`dead_recorder`（前任的记录仪，编号指向第七队）、`ark_misdrop`（错投给已阵亡小队的补给）、`mirror_pool`（倒影里的自己抬头微笑）三个事件都在敲他这个答案的裂缝。

**声音**：直、糙、行动优先。台词最少但落点最重。他的成长线是**从"砍"走向"看"**。

### 2.4 三角关系速查（写台词时的对照表）

| 事件类型 | 艾琳 | 诺亚 | 莱恩 |
|---|---|---|---|
| 遇到疑似有意识的星骸现象 | 想沟通 | 想测量 | 想戒备 |
| 遇到示好的异变生命 | 回应它 | 记录并上报 | 手不离刀 |
| 遇到前辈遗留物 | 难过 | 拆件回收 | 沉默（最危险的沉默） |
| 面对"用代价换力量" | 愿意付 | 先问利率 | 直接付，不问 |

## 三、叙事调性指南（写文本时的硬规则）

### 3.1 基调配比

**70% 冷峻 + 30% 人味。** 冷峻由环境、数据、术语承担；人味由三人的对话承担。顺序上通常是「冷描述 → 冷数据 → 一句人话收尾」，最后那句人话就是二次元感的落点。

`echo_cradle` 是这个结构的模板：低频描述（冷）→ 护目镜降噪失败三次、判定为"语言"（数据）→ 艾琳那句反问（人）。

### 3.2 七条纪律

1. **不解释设定。** 名词直接用（星骸、回响者、方舟、共鸣适性），靠语境让玩家自己拼。忌"如你所知"式科普。
2. **不点破苏醒。** 只给征兆，永远不给结论。见 §1.1 叙事纪律。
3. **具体压过宏大。** 写"水壶上的编号属于三年前失联的第七勘探队"，不写"这里曾发生惨剧"。**一个具体的物件 > 三句氛围形容。**
4. **不写形容词堆砌。** 恐怖来自不对劲的细节（威胁等级 0、倒影晚半秒、拔出来的刀是干的），不来自"恐怖的""诡异的"。
5. **两个选项都要对。** 选择 A（奖励）与选择 B（改线）不能有道德正解。A 通常是"取用"，B 通常是"理解或克制"，但 A 不该显得贪婪，B 不该显得高尚。
6. **单条事件长度控制在 100–160 字**（正文），选项文本 12–20 字。事件面板要在一屏内读完，玩家在割草间隙不会读长文。
7. **异变生命永远不说话。** 它们只**模仿**。一旦它们开口说人话，这个世界的悬念就塌了。

### 3.3 措辞速查

| 用 | 不用 |
|---|---|
| 星骸 / 腔体 / 肋层 / 结晶 | 神殿 / 圣所 / 魔法阵 |
| 回响者 / 探索者 / 勘探队 | 战士 / 冒险者 / 勇者 |
| 异变生命 / 异变体 | 怪物 / 魔物 / 邪魔 |
| 星尘（货币）/ 共鸣核心 | 金币 / 魔力 |
| 苏醒 / 收缩 / 心跳 | 复活 / 降临 / 觉醒（过于热血） |

### 3.4 事件文本模板

```
【环境冷描述：一个具体的、不对劲的物件或现象】
【一条来自设备的数据/判定，且这条数据本身很反常】
【一句人物台词，或一行档案文字，落在情感或悖论上】
```

## 四、剧情如何随角色成长解锁

叙事不是一次性播完的电影，而是**挂在成长曲线上的奖励**。四条解锁轨道并行：

### 4.1 轨道一：角色等级（局外养成 · 方舟基地）

每个英雄有 5 段个人剧情，按累计等级解锁，讲"这个人为什么还在往里走"。

| 等级 | 艾琳 | 诺亚 | 莱恩 |
|---|---|---|---|
| Lv.5 | 第一次共鸣的体检报告 | 拒签改造同意书的当天 | 走出星骸那天的询问笔录 |
| Lv.10 | 她开始记录自己的体温 | 炮台的命名规则（全是人名） | 星刃重铸的申请单 |
| Lv.15 | 与星骸的第一次"对话" | 他算出的伤亡预估模型 | 第七队最后一次通讯的残片 |
| Lv.20 | 她意识到自己在被改写 | 他发现联盟在用违规样本 | 那 40 小时的第一个碎片记忆 |
| Lv.25 | 「如果它醒了，我算它的谁？」 | 「合同我看懂了。我们是抵押品。」 | 那 40 小时的真相（留白结尾） |

### 4.2 轨道二：技能升级

主动技能每升一级，追加一条**技能注释**——一句话的技术+人性双关，是最廉价也最高频的叙事补给。

- 艾琳·火球 Lv3：「燃点每次都比上一次低。她没上报。」
- 诺亚·召唤炮台 Lv3：「这台叫 07。前面六台都没能带回来。」
- 莱恩·环绕星刃 Lv3：「刀在转的时候会发热。医生说那是他的心率。」

### 4.3 轨道三：潜能突破

突破是**改写角色状态**的节点，因此配套的是**分叉文本**：突破后角色的部分事件台词永久变化。

- 艾琳突破 → 她在事件中开始使用"我们"来指代自己和星骸（玩家一开始不会注意，这是本作最阴的一处伏笔）。
- 诺亚突破 → 他的台词开始出现第一次估算失误，并且他自己发现了。
- 莱恩突破 → 他开始在动手前问一句"这东西……刚才是不是在看我"。

### 4.4 轨道四：局内事件与 Boss 钩子

- **事件 flag 跨局继承**：`awakening_pulse` 选择 B（记录苏醒曲线）→ 解锁「苏醒档案」，在方舟基地永久开放一段核心剧情 + 一个研究项。这是主线唯一的推进通道，**必须让玩家主动选择克制才能拿到**——这是本作的设计表态。
- **Boss 腐化巨树**：战前钩子由 `corrupted_grove`（幼树全部朝同一方向排队）埋设；战后奖励解锁森林区域，并追加一条档案：树的年轮数量，恰好等于人类进入星骸的年数。
- **重复通关的叙事回报**：`signal_choir` 的呼号在多周目后会变化——异变生命的语调逐次更接近人类。这是不需要额外系统、只靠文本变体实现的长线收集。

### 4.5 解锁密度建议

| 阶段 | 玩家状态 | 叙事投放 |
|---|---|---|
| 首局 0–20 分钟 | 学玩法 | 只投放事件文本，不投人物剧情 |
| 通关 1–3 次 | 建立 Build 认知 | 开放 Lv.5–10 段人物剧情 + 技能注释 |
| 通关 4+ 次 | 追长线收集 | 潜能突破分叉、苏醒档案、多周目呼号变体 |

**原则：爽感优先，叙事永远不打断割草。** 所有剧情都在基地读，局内只有事件面板这一处停顿。
