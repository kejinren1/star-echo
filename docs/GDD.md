# 游戏设计文档 (GDD)

## 游戏名称
**星界土豆 (Astral Spud)** — 工作代号

## 一句话描述
俯视角自动射击肉鸽游戏 — 玩家在有限波次内生存，通过组合武器和道具构建不同流派，利用元素反应系统创造独特的战斗体验。

## 核心循环
1. 选择角色（不同初始属性/技能）
2. 进入波次（20~60秒，敌人涌出）
3. 自动攻击 + 走位躲避 + 拾取材料
4. 波次结束 → 商店（购买武器/道具/属性升级）
5. 重复直到 Boss 波 或 死亡
6. 死亡或胜利 → 解锁新内容 → 下一局

### 1.4 属性计算公式

**伤害计算:**
```
最终伤害 = (武器基础伤害 + 对应伤害属性) × (1 + 0%) × 暴击判定
暴击判定: if random() < 暴击率: × 暴击伤害倍率, else: × 1.0
```

**护甲减伤:**
```
伤害减免 = min(护甲 / (护甲 + 20), 0.75)
最终受伤 = 原始伤害 × (1 - 伤害减免)
```

**攻击速度:**
```
实际冷却时间 = 武器基础冷却 / (1 + 攻击速度%)
最低冷却时间 = 0.1秒 (硬下限)
```

**闪避:**
```
if random() < min(闪避率, 0.60): 完全无视该次伤害
```

**击退:**
```
击退距离 = 基础击退 + 击退属性值
被击退敌人速度 = 击退距离 / 0.2 (秒) → 0.2秒内减速到0
```

**收获材料:**
```
每波次结束额外材料 = 收获值
```

**幸运影响:**
```
商店高品质概率 = 基础概率 + 幸运 × 0.5%
宝箱掉落概率 = 基础概率 + 幸运 × 0.3%
```

**诅咒影响:**
```
敌人HP倍率 = 1.5 + 诅咒值 × 0.02
敌人伤害倍率 = 1.25
敌人速度倍率 = 1.15
材料掉落倍率 = 1.33
```

## 二、角色系统

### 2.1 角色概述

初始提供 6 个角色，各有独特被动技能和限制条件。角色差异体现在：
- 初始属性加成/减成
- 武器限制
- 独特被动机制

### 2.2 角色列表

#### 1. 均衡者 (Well-Rounded) — 初始角色
- **定位**: 全能型，适合新手
- **被动**: +10 最大生命值, +5% 移动速度, +3 收获
- **初始武器**: 手枪 (Pistol)
- **限制**: 无
- **设计意图**: 无特殊机制，让新手了解基础玩法

#### 2. 格斗家 (Brawler) — 近战特化
- **定位**: 近战爆发型
- **被动**: 使用近战武器时 +50% 攻击速度, +15 近战伤害, +10% 生命偷取
- **初始武器**: 拳头 (Fist)
- **限制**: 无法装备远程武器, -50 攻击范围
- **设计意图**: 高风险高回报，贴脸输出

#### 3. 游侠 (Ranger) — 远程精准
- **定位**: 远程风筝型
- **被动**: 使用远程武器时 +60 攻击范围, 远程伤害属性效果 +50%, +10% 暴击率
- **初始武器**: 弹弓 (Slingshot)
- **限制**: 无法装备近战武器, -25 最大生命值
- **设计意图**: 远距离安全输出，需要走位

#### 4. 法师 (Mage) — 元素大师
- **定位**: 元素反应型
- **被动**: +10 元素伤害, 元素武器有 30% 概率施加双倍元素状态, 元素伤害属性效果 +33%
- **初始武器**: 魔杖 (Wand)
- **限制**: -100% 近战伤害, -100% 远程伤害, -50 工程学
- **设计意图**: 利用元素反应系统打出爆发，本游戏的特色角色

#### 5. 工程师 (Engineer) — 召唤/工程型
- **定位**: 阵地战型
- **被动**: +15 工程学, 工程结构物生命值 +50%, 炮台/地雷伤害 +30%
- **初始武器**: 炮台 (Turret)
- **限制**: -20% 攻击速度, -10 近战伤害
- **设计意图**: 放置型玩法，靠结构物输出

#### 6. 赌徒 (Gambler) — 幸运/经济型
- **定位**: 经济滚雪球型
- **被动**: +50 幸运, 商店出现高品质物品概率 +25%, 拾取材料时 20% 概率获得双倍
- **初始武器**: 飞镖 (Shuriken)
- **限制**: -30% 伤害 (所有伤害类型), -20% 攻击速度
- **设计意图**: 前期弱，靠经济优势后期翻盘

### 2.3 角色解锁条件（后续版本）

| 角色 | 解锁条件 |
|------|----------|

### 3.4 武器升级

武器有 4 个等级 (I~IV)，可在商店中购买升级：
```
升级费用 = 当前等级基础价 × 1.5 (向上取整)
伤害提升 = 基础伤害 × (1 + 0.5 × 新等级)
冷却缩减 = 基础冷却 × (1 - 0.05 × 新等级)
```

### 4.3 元素反应设计意图

- 鼓励玩家混合使用不同元素武器
- 法师角色天生适配此系统
- 元素反应伤害受元素伤害属性加成，不会完全替代直接伤害
- 反应清除状态意味着需要重新施加，形成节奏感

## 十三、设计目标总结

### 13.1 核心体验
1. **流派自由度**: 6武器槽 + 4种伤害类型 + 元素反应 = 极高Build多样性
2. **决策密度**: 每波后的商店选择都有意义，20次决策决定整局走向
3. **即时反馈**: 自动攻击让玩家专注于走位, 操作门槛低
4. **渐进难度**: 20波难度曲线平滑上升, Boss波提供高潮

### 13.2 与Brotato的差异化
1. **元素反应系统**: 本作核心特色，鼓励混合元素武器
2. **工程系统增强**: 更结构化的工程武器体系
3. **角色更鲜明**: 每个角色有更强的机制差异
4. **波次类型多样**: 诅咒波/蜂群波等特殊波次增加变化

### 13.3 平衡性原则
1. 单一伤害类型堆叠 > 混合堆叠 (鼓励专精)
2. 元素反应补偿混合流派的劣势
3. 防御属性有上限 (护甲75%减伤, 闪避60%)
4. 经济投资 (收获) 有延迟回报, 需要前期取舍
5. 高风险高回报 (近战) vs 低风险低回报 (远程) 的基础平衡

| 材料获取 | 击杀 + 波次奖励 + 收获 |
| 商店品质 | 基础概率 + 幸运 × 系数 |
