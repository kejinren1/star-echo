## 一、为什么需要手动下载（重要）

spriters-resource.com 全站启用 **Cloudflare Turnstile 人机验证**。经实测：

| 通道 | 结果 |
|---|---|
| curl / 脚本直连 | ❌ 403（Cloudflare 拦截） |
| 无头浏览器自动化 | ❌ Turnstile 校验不通过（识别为机器人） |
| 图片 CDN 直连 | ❌ 同源被拦（`/media/assets/` 亦 403） |
| 代理/缓存/存档站 | ❌ 本机网络无代理；archive.org 不可达 |
| **真人浏览器（用户）** | ✅ 勾选一次验证框即可进入，Download 按钮正常 |

所以**唯一可靠下载方式 = 你在浏览器里打开链接点 Download**（每个 asset 页顶部有下载按钮）。全部素材约 **31 张图 / 33MB**，5 分钟内可下完。

## 五、下载后自动处理管线（我已备好）

```
ART/RAW/ss5sp/<角色名>.png   ← 你下载的整条 sheet
        │
        ▼  tools/ss5sp_sheet_split.py  （投影法自动切帧，输出逐帧 PNG）
ART/RAW/ss5sp/<角色名>_frames/xx_动作_帧号.png
        │
        ▼  tools/img2sprite.py（已有，抠底/降采样/量化，--bg-tol 100）
assets/sprites/...  （对齐 64px 基准 + ART/COLOR_DICT.json 调色板）
```

> 切帧脚本 `tools/ss5sp_sheet_split.py` 已写好，支持：自动检测帧边界（像素投影）、自动跳过空白间距、按行分动作、可选降采样到目标高度（如 64/128px）。
