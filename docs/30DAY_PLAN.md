## 〇、游戏身份定义（来自大纲）

- **一句话**：一款动漫像素风数值型肉鸽，融合《吸血鬼幸存者》的爽快割草 +《土豆兄弟》的 Build 构筑 +《明日方舟·集成战略》的路线探索与局外养成。
- **核心类型**：数值型肉鸽 / 自动攻击割草 / Build 构筑 / 随机路线探索 / 局外成长养成。
- **三大参考**：吸血鬼幸存者（大量敌人·自动攻击·数值成长·割草爽感）｜土豆兄弟（属性组合·Build 流派）｜明日方舟集成战略（随机地图路线·事件节点·局外养成·长线收集）。
- **MVP 范围**（大纲 §16）：角色 3 个 · 地图 1 张 · Boss 1 个 · 武器 15 个 · 被动 20 个 · 事件 10 个。
- **现有框架已具备**：移动、自动射击、命中/掉血、敌人接触伤害、HUD、金币掉落、数据驱动 JSON+帧 strip 管线、`baseline_check.py`/`build_release.py` 工程化工具。
- **待本冲刺补全**：英雄选择 + 3 签名武器、武器 Lv1-8 升级与进化、20 被动、随机节点地图、10 事件、两阶段 Boss、遗物、局外养成（方舟基地 + 研究系统）、Anime 像素美术与剧情文本。

## 一、三大风格（游戏性 / 美术 / 剧情）—— 由大纲建立

> 自动化 #7 在检测到 `游戏设计大纲.docx` 后建立本风格定义；自动化 #2 据此拆解每日任务。

### 1. 游戏性风格（Gameplay）

- **核心循环**：进入探索 → 随机生成地图 → 战斗 → 获得经验 → 选择强化 → 击败 Boss → 获得资源 → 返回基地 → 角色成长 → 再次探索。
- **操作**：移动（玩家控制）+ 主动技能释放（玩家控制，带冷却/资源）+ 路线选择（玩家控制）；**攻击自动释放**。
- **Build 构筑**：最多 6 武器槽 + 6 被动槽；武器 Lv1–Lv8（升级提升伤害/数量/范围/攻速）；10 属性（攻击力 / 攻速 / 范围 / 移速 / 暴击率 / 暴击伤害 / 生命 / 护甲 / 吸血 / 幸运）。
- **武器进化**：武器 Lv8 + 对应核心装备 = 进化武器（例：炎星术 Lv8 + 烈焰核心 → 炎星陨落：召唤大型火焰陨石 AOE）。
- **爽点哲学**：前 1 分钟理解「移动→自动攻击→击败」；5 分钟形成第一个 Build 流派（火焰流 / 召唤流 / 暴击流 / 吸血流）；20 分钟完成一次探索击败 Boss 获得永久资源。
- **肉鸽元素**：随机节点地图、文本事件抉择、精英、遗物（改变规则）、Boss 多阶段、局外永久养成。
- **难度哲学**：割草爽感为先，靠属性组合与 Build 深度提供长线挑战；路线抉择带来风险/收益博弈。

### 2. 美术风格（Art）—— 与现有 `ART_STYLE.md` 对齐说明

- **大纲方向**（§1.4）：Anime Pixel Art —— 二次元角色设计、平面像素风、高饱和幻想色彩、16bit 角色表现、华丽技能特效、科幻×幻想融合；角色有二次元立绘表现，战斗用像素 Sprite。
- **与现有 `ART_STYLE.md` 的对齐**：现有文档已定义**技术基底**（640×360 视口 / 整数缩放 / Nearest 过滤 / 像素对齐 / **64px 精灵基准**（角色 64×64，敌人 48×48~64×64，Boss 128×128）/ **216 色上限·字典登记制**（锚点色板 32 色硬锚点 + 容差归并 ΔRGB≤12）/ **1-2px 描边** / **透明键协议**（左上角像素=背景色）/ 色号编码 / 数据驱动帧 strip）。**保留全部技术基底**，仅将**方向层**从「暗色像素·硬朗轮廓·霓虹点缀」调和升级为 **「Anime 像素 · 高饱和幻想 · 华丽特效」**：
  - 角色：二次元立绘语言（表情/姿态辨识度）+ 像素 Sprite 实现，保留 1-2px 描边但轮廓更圆润有辨识度。
  - 色彩：在 216 色字典制内提升幻想色饱和度（32 色锚点色板作关键色硬锚点；青/品红/电黄霓虹保留作技能特效光源）。
  - 技能特效：要求「华丽」——粒子层次、暴击弹字、进化/毒雨大招表现力；特效色机制（升级奖励规则绑定）见 ART_STYLE.md Backlog。
  - ⚠️ **执行策略注记（用户拍板 2026-08-07 21:1x，见 §三 D23）**：风格方向「华丽特效」保留为**长期目标**，但当前冲刺**不再投入生成美术资源**（AI 画图能力有限；缺口一律占位纯色图保证功能可检测）。D23 特效按「占位实现机制」落地（色块粒子/简单发光/AnimatedSprite 复用），**不做华丽 VFX**；表现力为主观项交人工，#2 拆解 D23 时不得将「华丽」设为验收标准（§三 L96 已登记）。
- **决定权**：美术方向最终由自动化 #7 结合大纲与 `ART_STYLE.md` 定稿；**不覆盖** `ART_STYLE.md` 的技术规格，只在方向上追加「anime」调和（见 `docs/ART_STYLE.md` 二·美术风格定位 + 十四·标准图像规格总表速查；方向细则见 `docs/ART_ANIME_SPEC.md`）。
- **资产清单**（MVP）：3 英雄 Sprite（艾琳/诺亚/莱恩，含立绘表现 + 战斗帧 strip）、敌人/Boss（腐化巨树）、武器/被动图标、技能 VFX、UI 资源。

### 3. 剧情风格（Story）

- **世界观基调**（大纲 §3）：未来世界人类发现巨大生命遗迹「星骸」——拥有改变物质规则之力、不断产生异变生命；人类成立「回响者联盟」进入探索、吸收遗迹力量强化自身；核心悬念：**星骸并非死亡遗迹，它正在苏醒**。
- **叙事载体**：① 事件节点文本抉择（10 事件，描述 + 选择A奖励 + 选择B改线）；② 角色培养解锁剧情（等级 / 技能升级 / 潜能突破 → 解锁角色专属剧情）；③ Boss 战前后叙事钩子（腐化巨树 → 解锁森林区域）。
- **台词调性**：二次元轻小说感，带科幻冷峻底色；神秘探索 + 逐步揭示星骸苏醒的悬念。
- **主题关键词**：遗迹、回响、异变、苏醒、探索者、方舟。

## 五、需人工介入的环节（自动化无法替代）

以下类型**明确标记给人工**，不尝试自动试玩，由自动化 #5 汇总到 `docs/PLAYTEST_CHECKLIST.md`：

- 游戏手感 / 操作反馈是否「跟手」（移动、自动射击节奏、技能释放手感）。
- 难度曲线体感（太难 / 太肝 / 无聊）；割草爽感是否到位。
- 数值是否「好玩」（自动只能验边界，不能验乐趣；Build 流派是否有趣）。
- UI / UX 顺畅度与可读性（6 武器 + 6 被动槽布局、升级选择面板）。
- 视觉 / 听觉主观感受（Anime 像素落地、华丽特效表现力、音频氛围）。
- 剧情文本调性（二次元轻小说感 + 科幻冷峻是否自然）。
- 崩溃复现需真人操作路径。
